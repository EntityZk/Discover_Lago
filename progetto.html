Obiettivo

Informazioni chiare, navigazione semplice.

Il sito è un progetto didattico: presenta alcune mete del lago e offre spunti per organizzare una visita, con particolare attenzione a leggibilità e uso da smartphone.

⌘

HTML5 semantico

Le pagine usano header, nav, main, section, article e footer per rendere la struttura comprensibile e ordinata.

▦

CSS responsive

Grid, Flexbox, variabili CSS e media query permettono di adattare i contenuti a schermi di dimensioni diverse.

✓

Accessibilità di base

Le immagini hanno testi alternativi, il menu è navigabile da tastiera e il link “Salta al contenuto” riduce i passaggi ripetitivi.

Lavoro di gruppo e tracciamento.

Il repository usa Issue, branch, commit e pull request per organizzare le attività. Il registro TPSIT documenta solo operazioni realmente svolte.
