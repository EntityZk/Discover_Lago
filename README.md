# Discover_Lago
Discover Lago è un portale turistico in HTML/CSS sul Lago Maggiore. Strutturato con una home page e tre sezioni (Località, Escursioni, Alloggi e Info), il sito è stato realizzato in team tramite Git e GitHub, applicando il flusso di lavoro collaborativo con branch, Issues, Pull Request e risoluzione dei conflitti.
