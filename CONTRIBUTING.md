# Contribuire a Discover Lago

Grazie per voler migliorare il progetto! Per mantenere il ramo principale ordinato, usa un branch separato e una Pull Request.

## Procedura

1. Aggiorna il tuo branch locale: `git switch main && git pull origin main`.
2. Crea un branch descrittivo: `git switch -c feature/descrizione` oppure `fix/descrizione`.
3. Mantieni le modifiche focalizzate e coerenti con HTML5 e CSS3, senza introdurre dipendenze non necessarie.
4. Verifica tutti i link interni, i percorsi delle immagini e il layout a larghezze desktop e mobile.
5. Controlla la navigazione da tastiera, il testo alternativo delle immagini e il contrasto.
6. Usa messaggi di commit chiari, ad esempio `feat: aggiunge una sezione`, `fix: corregge un collegamento`, `docs: aggiorna il README`.
7. Pubblica il branch e apri una Pull Request verso `main`, descrivendo cosa è cambiato e come hai verificato il risultato.

## Criteri di qualità

- HTML valido e semantico, con un solo titolo principale chiaro per pagina.
- CSS condiviso, variabili coerenti e regole responsive.
- Nessun link fittizio o funzione presentata come funzionante se non lo è.
- Contenuti informativi formulati con precisione; verifica le fonti aggiornate prima di riportare orari o tariffe.
- Rispetta i diritti d'uso e le attribuzioni di immagini, font e altre risorse esterne.
