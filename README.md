Discover Lago è una guida turistica web sul Lago Maggiore progettata in HTML5 e CSS3 per il laboratorio di TPSIT.

Il sito si articola su quattro pagine interconnesse:

index.html: Home page con presentazione e navigazione generale.

sezione-a.html: 5 località principali (Stresa, Verbania, Cannobio, Luino, Arona).

sezione-b.html: 4 attività ed escursioni (Mottarone, tour in battello, Val Grande, sport acquatici).

sezione-c.html: Informazioni pratiche su alloggi, trasporti e consigli di viaggio.

Workflow Git/GitHub:

Il progetto simula un ambiente di lavoro aziendale. Il Project Manager ha impostato il repository e le Issues; gli sviluppatori hanno lavorato su branch separati (sezione-a, sezione-b, sezione-c), pubblicato i contenuti tramite Pull Request ed eseguito le correzioni richieste in fase di revisione. Infine, è stato generato e risolto un conflitto di fusione su index.html per testare la gestione di modifiche concorrenti sul ramo main.
